🚀 Bộ Nhớ Tạm Tốc Độ Cao (Redis Cache Store)

                

                    Redis lưu cấu trúc cây công tơ ghép tổng - phụ (Netting topology) và Snapshot dữ liệu hợp đồng
                    khách hàng để chốt cước trên RAM trong <10ms.
                


                

                    

                        

                            Key: billing:book_status_hash:{Book_ID}

                        

                            Cấu trúc Hash lưu trữ trạng thái chốt cước live của từng khách hàng thuộc Sổ. Hỗ trợ
                            Worker kiểm tra trạng thái cuốn chiếu cực nhanh.
                        

                        
HGETALL billing:book_status_hash:SO_Y1
1) "KH0001" -> "SUCCESS"
2) "KH0002" -> "ANOMALY"
3) "KH0003" -> "PENDING"

                    


                    

                        

                            Key: snapshot:{Account_ID}:{Month}

                        

                            Lưu trữ chuỗi JSON cấu hình định mức khách hàng dùng chung, biểu giá áp dụng và cây phả
                            hệ công tơ (Netting) nạp sẵn từ CMIS để tính toán.
                        

                        
GET snapshot:KH0001:2026_06
{
  "accountId": "KH0001",
  "normsFactor": 1,
  "nettingType": "PARENT",
  "children": ["KH0001_SUB1", "KH0001_SUB2"]
}
